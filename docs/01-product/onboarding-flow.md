# Introduction

This document defines the first-time user onboarding experience for PAO COMPANION.

The purpose of onboarding is to transform a new visitor into a companion owner by creating a personalized AI Girlfriend or AI Boyfriend experience.

The onboarding experience must achieve three objectives:

1. User understands what PAO is.
2. User successfully creates their companion.
3. User experiences the first meaningful interaction.


# Onboarding Philosophy

PAO onboarding follows:

## Create → Meet → Connect

The user should not feel like they are configuring software.

The user should feel like they are meeting someone new.
